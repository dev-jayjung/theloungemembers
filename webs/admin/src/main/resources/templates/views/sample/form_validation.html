Form & Validation 유틸리티 가이드

1. FormUtil (Form 직렬화 및 기본 조작)
FormUtil.serialize()를 통해 Input 항목들을 JSON Object로 자동 변환하고[cite: 2], FormUtil.reset()으로 입력값을 초기화합니다[cite: 2]. 
결과가 여기에 표시됩니다.
2. FormUtil.validate (상세 유효성 검사 패턴)
HTML Class 속성에 validate[규칙]을 적용하여 다양한 조건(필수, 자릿수, 비밀번호 비교 등)을 검증합니다.
3. ValidationUtil (단일 값 개별 검증)
ValidationUtil.isEmpty(), isValidPassword(), isValidDate() 등의 정밀 검증 함수를 제공합니다[cite: 1].
