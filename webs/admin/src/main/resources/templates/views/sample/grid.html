Tabulator 그리드 컴포넌트 가이드

1. 검색 조건 및 폼 연동 (Search Form & FormUtil)
검색 조건 폼은 table_type1 구조를 사용하며, GridUtil.init()의 ajaxParams 옵션에서 FormUtil.serialize('#searchForm')을 통해 그리드 파라미터로 자동 전송됩니다.
검색조건 서비스 코드
IP 검사 해제 LMS 통지 허용
사용 여부 API 정보 메뉴
2. 그리드 컨트롤 및 데이터 목록표 (Tabulator)
상단 mButton typeBorad 영역에 pageSize 공통 프래그먼트와 엑셀 다운로드, 등록하기 등의 보조 액션 버튼을 배치합니다.
페이지 크기 변경 드롭다운 선택 시 그리드에 즉시 반영되며, 헤더 우측 메뉴(Column Header Menu)를 통해 컬럼 숨김/표시 조작이 가능합니다.
