팝업(Popup) 컴포넌트 가이드

1. 공통 레이어 팝업 (LayerUtil / Promise 기반)
LayerUtil.open(config)을 통해 모달 레이어 팝업을 동적으로 생성 및 제어합니다.
Promise 객체를 반환하므로 .then() 또는 async/await 구문으로 결과 처리가 가능하며, onConfirm 옵션을 통해 닫히기 전 유효성 검증을 수행할 수 있습니다.
2. 도메인별 공통 모듈 팝업 (CommonPopup)
자주 쓰이는 업무용 팝업(업체 조회, 사용자 검색 등)은 CommonPopup에 모듈화하여 호출합니다.
내부적으로 AjaxUtil로 HTML을 로드하고 선택된 데이터를 callBack으로 상위 화면에 전송합니다.
3. 공통 윈도우 팝업 (WindowUtil)
WindowUtil.open(config)을 통해 브라우저 새 창 팝업을 오픈합니다.
듀얼 모니터 환경에서도 브라우저 중앙에 오도록 위치(left, top)를 자동 계산하며, data 파라미터 전달 시 동적 Form 생성을 통해 POST 전송을 지원합니다.
