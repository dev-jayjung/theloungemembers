탭(Tab) 및 프레임 제어 유틸리티 가이드

1. 새 탭 오픈 (TabUtil.openTab)
TabUtil.openTab(param)을 통해 상단 메인 프레임에 새 탭을 추가합니다.
data 객체를 전달하면 자동으로 QueryString으로 변환하여 URL에 머지되며, tabName 생략 시 메뉴 API에서 명칭을 비동기로 가져옵니다.
2. 탭 종료 및 정리 (TabUtil.closeSelf / closeAllTabs)
현재 활성화된 본인 탭을 닫거나(closeSelf), 열려있는 모든 작업 탭을 일괄 정리합니다(closeAllTabs).
