좌측에 treeMenu(jsTree 영역)를, 우측에 treeContent(상세 폼)를 배치하는 표준 구조입니다.
서버 응답 필드명에 맞게 mapping 옵션만 지정하면 jsTree 규격(id, parent, text)으로 자동 변환됩니다.
