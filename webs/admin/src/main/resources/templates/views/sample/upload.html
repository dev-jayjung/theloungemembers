S3 파일 및 이미지 업로드 컴포넌트 가이드

1. 일반 첨부파일 업로드 컴포넌트 (fileUpload)
공통 프래그먼트 fileUpload를 활용한 단일 문서/일반 파일 첨부 UI입니다.
S3 Direct Upload 수행 후 서버로 제출될 keyName(S3 Key)과 fileName(원본 파일명) Hidden 필드가 자동 생성됩니다.
기본 사용
(기본 옵션 적용)
옵션 커스텀
(제한/파라미터 변경)
* 허용 확장자: PDF, DOCX, ZIP / 용량 제한: 5MB / Input 너비: wth250
수정 화면
(기존 데이터 바인딩)
2. 단일 이미지 업로드 컴포넌트 (imageUpload)
대표/서브 이미지 첨부 UI입니다. 용량 제한(maxSize) 및 이미지 해상도 제한(maxWidth, maxHeight)을 지원합니다.
기본 사용
(기본 옵션 적용)
옵션 커스텀
(파일명 저장 & 규격 제한)
* 허용 확장자: JPG, PNG / 용량 제한: 2MB / 최대 가로 너비: 1920px
수정 화면
(기존 이미지 미리보기)
3. 서버 제출(Form Submit) 데이터 테스트
업로드 후 생성되는 Hidden 필드의 th:name 값이 서버 DTO로 바인딩되는 구조입니다. 버튼을 클릭해 현재 바인딩된 값을 확인하세요.
